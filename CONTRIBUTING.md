# Contributing

Thanks for your interest in Freecorps Brigade!

## Current state

The project is in its design phase. The best way to help right now is to read the
[RFCs](docs/rfcs/) and the [open questions](docs/open-questions.md), and open an issue or discussion.

## Contributor License Agreement

**We cannot merge external code contributions yet.** All contributors will need to sign a CLA so that
Freecorps can distribute the mobile apps through the app stores and offer dual licensing
(see [RFC 0009](docs/rfcs/0009-licensing-and-governance.md)). The CLA is being prepared.

## Development setup

1. Install [Vite+](https://viteplus.dev/guide/) (`vp`).
2. `vp install`
3. `vp check` and `vp run -r test` before opening a pull request.
